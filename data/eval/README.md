# 评测题集

`questions_v1.jsonl` 有10道真实来源多跳题：2跳、3跳各5道，覆盖通识教育、学科基础、专业基础、专业课程和实践教学。由已有审核图谱的开发问题迁移，AI依据原文补充答案与要点；不是独立人工盲测集。所有题的标准边均在当前已核验图谱中，`source_evidence_ids` 保留来源定位。

`questions_v1.sha256` 冻结精确文件字节。修改后必须重新审核并生成新哈希；系统在提交评测和开始执行时分别验证，防止提交后变更题集。`negatives.jsonl` 含缺年级、选择与问题冲突、领域外问题3例，其哈希随每次运行配置持久化。

指标（评分版本0.2.0）：

- 路径命中率：正例中输出路径与标准边集合完全一致的比例，另列2/3跳分项。
- 答案要点命中率：终态正确且包含全部来源要点的比例，含13题；数值按完整数字匹配。
- 引用覆盖率：可从响应批次独立读回全部引用的断言数 / 断言总数，无断言时N/A。
- API生成占比：10道正例中 `answer_mode=llm` 的比例，模板摘录不会计入。
- 耗时：13题端到端耗时平均值、P95。

自动要点匹配不能判断否定、条件适用或语义是否正确，需要逐题人工复核。当前题集的主题较集中，后续应在扩图后增加未参与调参的独立问题。

网页和 `python -m scripts.run_eval` 共用服务与问答pipeline。每次运行保存 `records.jsonl`（含完整响应、逐跳记录）和 `summary.json`，SQLite同步保存逐题详情，可通过网页导出 Markdown。CLI还写入 `report.md`。`runs/`为运行产物，不进Git。
