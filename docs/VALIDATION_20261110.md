## 复现与日常使用

当前服务已经运行。下次在根目录启动：

```powershell
.\start-local.ps1
```

修改`.env`后重载：

```powershell
.\stop-local.ps1
.\start-local.ps1
```

仅更换嵌入模型、端点或维度且需要新向量时使用`-RebuildEmbeddings`，会产生嵌入API用量。迁移电脑还需复制未入Git的`data/raw/`原始PDF，按新工作空间配置决定复用或重建向量。

非外部服务测试从backend目录运行`..\.venv\Scripts\python.exe -m pytest -m "not integration"`。真实Neo4j集成测试需设置`INTEGRATION=1`、新容器的`NEO4J_URI`及密码，运行`pytest tests/integration -m integration`；测试使用独立临时SQLite与索引。正式真实API评测可在网页“评测中心”启动，每次会产生模型调用用量。
